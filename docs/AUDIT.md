# Аудит ShelfBridge · 4 жовтня 2026

Локальний прототип працює; знайдені нижче помилки виправлено. Готовність до
публічного live-запуску не підтверджено: залишаються перевірка Qloo, зіставлення
книг, успішний запуск Qloo/LLM і перевірка хостингу.

Перевірено сервер, політику відбору, провайдери, бюджет викликів, UI, тести,
скрипти перевірки й інструкції запуску. Зовнішні API не викликалися; реальні
ключі не використовувалися. У каталозі залишаються 30 творів і 31 демонстраційний
SKU; ціни й залишки симульовані.

## Докази

- До змін: **27/27** наявних тестів проходили. П'ять нових серверних перевірок
  запущено окремо на збереженому початковому коді: **5/5 виявили помилки**.
  Після виправлень усі ці перевірки проходять.
- Після змін: **42/42** тести Node, без пропусків; **18/18** браузерних
  сценаріїв Chrome, без JavaScript-помилок.
- Перевірено затримки й завеликі потоки, ізоляцію та строк дії сесій, збої,
  перезавантаження, вичерпання уточнень, клавіатуру й екран 390 px без
  горизонтального переповнення. Desktop/mobile знімки переглянуто.
- Live-приклад у браузерному тесті симульований локальними відповідями.
  Він перевіряє UI і кількість запитів, не реальну інтеграцію Qloo.

`npm test` запускає серверні перевірки. `npm run test:browser` запускає окремий
локальний fixture-сервер на вільному порту та завершує його після перевірки.
Для браузерної перевірки потрібен Playwright у development-середовищі:
`PLAYWRIGHT_PACKAGE_PATH` може вказувати на наявний пакет,
`BROWSER_EXECUTABLE` — на Chrome. `SHELFBRIDGE_TEST_URL` дозволяє явно обрати
наявний fixture-сервер.

Локальні докази: `test-results/audit-tests.txt`, `browser-report.json`,
`audit-before-regressions.txt`, PNG-знімки та `audit-changes.diff`.
Початкові файли збережено у `test-results/audit-before/`. Ця папка і докази
ігноруються правилами проєкту. У робочій папці немає Git-репозиторію,
тому коміт або PR не створювався.

## Що залишається відкритим

1. **P00 / Qloo:** підтвердити реальний контракт, точні ідентичності книг і
   культурне покриття. Пороги 24/30 книг та 8/10 профілів із плану залишаються
   неперевіреними. Захисний прапорець контракту не знімався.
2. **Реальний LLM/Qloo-сценарій:** потрібен успішний запуск. Попередній звіт
   про OpenAI 429 збережено; цей аудит не повторював платний smoke-запит.
3. **Якість рекомендацій:** немає незалежних результатів користувачів або
   доказу переваги адаптивного агента над базовим ранжуванням.
4. **Публічний запуск:** потрібні зовнішня HTTPS-перевірка, постійний том для
   бюджету, ліміт витрат у провайдерів і перевірка доступності сервісу.
   Поточний ledger розрахований на один процес; захист від зловживань
   публічним сервісом і повний аудит доступності цим проходом не підтверджені.

Фізичний друк, системний буфер обміну, повна WCAG-відповідність і навантажувальні
характеристики не перевірялися. Публічний реліз залишається **NO-GO**, доки
відкриті release gates з [VALIDATION.md](VALIDATION.md) не закрито.
